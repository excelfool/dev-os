# MSA instructor golden set

`golden-set.json` is the instructor's 10-contract MSA golden set (copied verbatim from the course material; see `docs/reference/prd-alignment-recommendation-2026-09-21.md`).

The contract PDFs are **not committed**. Download each one from the `pdf_source_url` link in `golden-set.json` and save it as `pdfs/<tab>.pdf`, where `<tab>` is the contract's `tab` value in the golden set. The `pdfs/` folder is git-ignored.
